Put the ARM64 Windows libsndfile here (see ../README.md for full steps):

PREFERRED - one self-contained DLL (deps linked in statically):
  libsndfile.dll      (single file; rename from the mixed-triplet sndfile.dll)
  LICENSE-*.txt       (libsndfile LGPL + each bundled dependency's license)

ALTERNATIVE - plain dynamic build:
  libsndfile.dll      (rename from vcpkg's sndfile.dll)
  <dependency DLLs>   (FLAC.dll, ogg.dll, vorbis.dll, opus.dll, mpg123.dll, ...)
  LICENSE-*.txt

Once the file is here it auto-loads on ARM64 Windows (source runs) and is bundled
into ARM64 builds. Delete this file once the real DLL is in place.
